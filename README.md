# 特战队射击游戏 2D

一款横版侧视 2D 团队射击游戏，类似魂斗罗风格。

## 游戏特性

- **5v5 团队对战** - 选择蓝队或红队，与 AI 队友一起作战
- **可切换队友** - 按 Tab 或数字键 1-5 切换控制任意队友
- **双武器系统** - 主武器 + 副武器（手枪），按 Q 快速切换
- **5 种枪械** - 手枪、冲锋枪、步枪、狙击枪、霰弹枪
- **完整动作系统** - 移动、跳跃、蹲下、瞄准、射击、换弹、近战
- **智能 AI** - 自动寻敌、射击、撤退
- **三层平台地图** - 多层地形设计
- **击杀提示** - 底部中央显示击杀信息，带音效
- **记分板** - 按 P 暂停显示双方 K/D 统计

## 操作说明

| 按键 | 功能 |
|------|------|
| W / ↑ | 跳跃 |
| A / ← | 向左移动 |
| S / ↓ | 蹲下 |
| D / → | 向右移动 |
| 鼠标 | 瞄准 |
| 左键 | 射击 |
| R | 换弹 |
| F | 近战攻击 |
| Q | 切换主/副武器 |
| Tab | 切换下一个队友 |
| 1-5 | 切换到指定队友 |
| P | 暂停/记分板 |
| U | 切换无敌模式（调试） |

## 枪械数据

| 枪械 | 伤害 | 射速 | 弹匣 | 特点 |
|------|------|------|------|------|
| 手枪（副武器） | 25 | 3 发/秒 | 12 | 平衡型，可切换 |
| 冲锋枪 | 15 | 10 发/秒 | 30 | 高射速，扩散快 |
| 步枪 | 30 | 5 发/秒 | 20 | 中距离，稳定 |
| 狙击枪 | 60/150(爆头) | 0.5 发/秒 | 5 | 爆头一击必杀 |
| 霰弹枪 | 20×8 | 1 发/秒 | 6 | 近战散射 |

**扩散机制**：连续射击会增加枪械扩散，停止射击 1.5 秒后恢复。不同武器扩散增长率不同（冲锋枪最快，狙击枪最慢）。

## 运行方式

### Windows
双击 `index.html` 文件，在浏览器中打开即可运行。

或者使用本地服务器：
```bash
# Python 3
python -m http.server 8080

# Node.js (需要安装 http-server)
npx http-server -p 8080
```

然后在浏览器访问 `http://localhost:8080`

### 浏览器要求
- Chrome 80+
- Firefox 75+
- Edge 80+
- Safari 13+

## 技术栈

- **纯前端** - HTML5 + CSS3 + JavaScript (ES6)
- **Canvas 渲染** - 矢量图形，5 部位分层动画
- **Web Audio API** - 合成音效，无需外部音频文件
- **对象池优化** - 子弹/粒子复用，减少 GC 压力
- **空间网格哈希** - 优化碰撞检测性能
- **视锥剔除** - 只渲染屏幕内对象

## 游戏规则

1. 选择队伍（红队/蓝队）和主武器
2. 设置游戏时长和目标击杀数
3. 开始游戏，消灭敌方队伍
4. 先达到目标击杀数或时间结束后击杀数多的队伍获胜
5. 死亡后 3 秒在出生点重生，重生后 3 秒无敌时间（身上发光提示）
6. 按 P 暂停可查看双方 K/D 统计
7. 按 Q 切换主副武器（副武器固定为手枪，1 秒换弹）
